# GyanMarg - Frontend

React + Vite + Tailwind CSS v4 frontend for the GyanMarg educational platform.

## Setup

```bash
npm install
```

Create a `.env` file (refer `.env.example`):

```
VITE_API_URL=http://localhost:5000/api
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```
